author: "Krishay Bugatha (bugatha2)"
---

An AI agent is asked to build and evaluate a KNN model. It automatically standardizes the predictors using the entire dataset before splitting the data into training and test sets. The resulting test accuracy looks unusually high. What is wrong with the agent's approach? Explain how this creates data leakage, how it could affect the estimated test performance, and how the workflow should be changed to evaluate the KNN model honestly.
